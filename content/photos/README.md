# Photos for the photo tasks

Put `.jpg`, `.png` or `.webp` files in this folder to practice **Write About the Photo** and
**Speak About the Photo**.

Like the real test, use real photos of people, animals or objects in everyday situations.
Free sources: [Unsplash](https://unsplash.com), [Pexels](https://www.pexels.com), or your own pictures.

The photos stay on your computer: git ignores this folder (except this README).
